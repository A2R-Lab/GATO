# Dynamics

- `plant.cuh` — the shared, robot-agnostic plant adapter (dimensions from `grid::`
  constants, dynamics + tracking-cost wrappers over the generated `grid_plant::` surface).
- `<robot>/grid.cuh` — generated by [GRiD](https://github.com/A2R-Lab/GRiD)
  (`tools/regen_grid.py` or `gato.build`).
- `<robot>/limits.cuh` — joint/velocity/effort limit tables generated from the URDF
  `<limit>` tags alongside `grid.cuh`.

Each `(plant, N)` module compiles `plant.cuh` with the robot's directory on the
include path, so adding a robot is purely generative — no C++ edits.
